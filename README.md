# nvlide

Per-app volume sliders for Nothing phones, built into a Nothing OS-style volume panel.

Press a volume key → the familiar pill slider. Expand → media / call / ring / alarm. Expand again → one slider
for every app that is playing audio. Levels are remembered per app and re-applied every time it plays again,
even after you close it or reboot.

Runs without root via [Shizuku](https://shizuku.rikka.app/).
